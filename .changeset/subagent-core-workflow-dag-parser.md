Adds a static workflow blueprint parser and richer run-journal fold projections for workflow visualization consumers. `parseWorkflowDag` is now exported from the package root (together with `WORKFLOW_DAG_DEFAULT_PHASE` and the `WorkflowDag` type family: `WorkflowDagNode`, `WorkflowDagEdge`, `WorkflowDagEdgeKind`, `WorkflowDagPhase`, `WorkflowDagParallelGroup`, `WorkflowDagLoop`, `WorkflowDagNodeKind`, `WorkflowDagParseResult`): it parses a workflow `scriptSource` into a DAG with template agent names preserved, four edge kinds — including dataflow edges derived from member-access references such as `r1.output` — plus phase partitions, parallel groups, and loop back edges paired by `loopId`. Parse failures throw structured errors instead of returning a partial DAG. The run-journal fold gains optional, purely additive projections: `RunAskStepFold` now carries `attempts` (cumulative failure count), `lastRetry` (`attempt`/`backoffMs`/`reason` snapshot), and `usage` (token breakdown from the settled result), and `RunJournalFold.created` carries `argsSummary`; existing consumers are unaffected since every new field is optional. Ships one new bundled runtime dependency, `acorn` (inlined into the dist bundle via `noExternal`).
