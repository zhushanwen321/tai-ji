# 字重三档令牌落地后的 CJK 渲染核验（D8 移出项的残余验证）

状态：**CJK 三档观感核验完成（2026-10-12，核验通过，无发糊/拥挤/变形）**；三档令牌维持 500/600/700 不动。「加重」整体模式维持「等真实使用反馈」挂起（无既定时点）。登记来源：ui-signal-density 设计 D8「本轮移出本次范围」

## 现状（终态）

`packages/renderer/src/style.css` 三档字重令牌为 `--fw-text: 500` / `--fw-mid: 600` / `--fw-bold: 700`（2026-10-08 commit 28f1c8555 将 400/500/600 整体上移一档，档差不变；docs/DESIGN.md §4.6 同批回写）。正文 500、行容器/块标签/工具名 600、markdown 标题与强调 700（消费点以代码为准：`packages/ui/src/features/chat/Block.vue` 系列行头 `[font-weight:var(--fw-mid)]`、`MarkdownRenderer.vue` 标题 `--fw-bold`）。demo 的「加重」整体切换模式（各档 +100，对标 xterm fontWeight/fontWeightBold）未实现。

## 核验结论（2026-10-12，原待做 1）

- **方法**：① 独立采样页——字体栈与 `--font-sans` 逐字一致（macOS 命中 PingFang SC）、不设 font-smoothing（与 app 同走系统默认），真机 Chromium 按 1x（非 Retina）与 2x（Retina）双档截图，采样覆盖 400/500/600/700 × 13px/12px/11px × 亮/暗主题；② 应用层证据 = 2026-10-11 本地重录的 shell 像素基线（真实 UI：侧栏会话名 600、问候语 700、导航项 500）。
- **结论**：原 D8 登记的 C5（500 正文发糊）风险未现形——500 与 400 在 13px 下笔画分离清晰、无横画粘连，11/12px 小字号同样成立；600 行容器观感干净；700 无拥挤与合成加粗变形；暗色主题下无异常。三档维持现状，不需回调。
- **边界**：核验机器为本工作机单机结论（Apple 显示器）；外接非 Retina 屏的观感如收到用户反馈再单点复核。

## 挂起项

「加重」整体模式（用户可切换的 +100 档）是否立项——等真实使用反馈，无既定时点。
