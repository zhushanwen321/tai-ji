## 移出理由

- 收益只表述到「对话流层级」的补强，无独立三问论证；设计自判 700 档「收益未证」。
- 两项待验证风险：C5 = CJK 在 500 字重下发糊；C6 = 600 → 700 的档差是否可感知。
