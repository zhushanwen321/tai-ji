# 断连窗口 dialog 请求丢失残留（remote-use D3 已接受代价）

状态：已接受代价，低频残留——不修；用户报告或 W5 立项时复审。设计依据：`.tmp/tech-design/remote-use-shell-unification.md` §3.3 D3 不采用①后的残留四要素。

## 现象

断连窗口（弱网掉线、锁屏超探活窗）内到达的 dialog 请求（extension 确认/提问）静默丢失：请求未入移动端分区，重连后不补投（重连对账明示不覆盖 dialog 通道——dialog 排队语义与 form 差集对账不同构，共用翻译层需重设计）。

## 量级

弱网远程形态下断连窗口非极端个例（远程访问以弱网为常态前提）。丢失频率 = 会话中 dialog 触发频率 × 断连窗口时间占比。本波已封住「页签切换」这一高频窗口（D3 根级常驻：任意页签可见可作答），断连窗口为低频残留。

## 恢复路径

无自动恢复。用户侧手动恢复 = 桌面端作答（桌面 CompanionBand 常驻仍显示该请求）。双端均未作答时发起方无限等待。

## 判定

可接受：对账方案治标且需动共享翻译层，复杂度与低频残留不成比例。

## 重审触发

远程形态用户报告 dialog 丢失，或 W5 连接维持波立项时随连接健壮性一并复审。
