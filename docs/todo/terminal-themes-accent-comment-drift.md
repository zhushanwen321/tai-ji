# terminal-themes.ts 注释与 accent 实值漂移（存量登记，清洁项）

状态：未修（登记不修——注释与实值在 accent 令牌改动前已经不符；改它属「让注释与实现一致」的清洁项，与令牌改动解耦）。登记来源：ui-signal-density 设计 D3「存量漂移一处（登记不修）」

## 问题

`packages/renderer/src/composables/terminal/terminal-themes.ts` 行 20 / 22 / 31 把硬编码冷蓝 `#4f8ef7` 注释为 `--accent`，而 `--accent` 实值与此不符——注释指认的令牌关系是错的。该冷蓝色相已被 ADR-0066 推翻，注释还把它当作 accent 的落点描述。

## 处置边界

- 这些 hex 是**硬编码值**，不随 `--accent` 令牌改动自动跟随——改 accent 值不会让这里的注释变得更对或更错，两件事解耦。
- 修法 = 把注释改为如实描述（「终端自有冷蓝硬编码色，与主题 accent 令牌无关」或按实际语义重写），不改任何色值、不改运行时行为。
- 顺带可核对同文件是否还有其他令牌名与硬编码值混写的注释（设计只登记了上述三行，未全文件核查）。
