# ADR-0066: 视觉色相定为太极·玄纯灰重克制（V3）

- 状态：Accepted（2026-08-02 决策，2026-09-13 自 page-design 临时决策文档转正）
- 值权威：[`style.css`](../../packages/renderer/src/style.css)（值真值；登记对照见 [DESIGN.md §4](../DESIGN.md)。本 ADR 不复制色值表；提案值与定稿值曾有微调，如 `--accent` 提案 `#c8c8cd` → 定稿 `#cfcfd4`）

## 背景

2026-08 之前 v6 为冷蓝暗色系（`--bg #1a1b1f` / `--accent #4f8ef7`），与产品的太极概念（阴阳 / 相生相克 / 周而复始）无关。经三轮对比确定方向：三套色相方案（墨青 / 墨朱 / 纯太极）中选纯太极；纯太极四档克制梯度（浅 V1 / 中 V2 / 重 V3 / 极简灰度 V4）中选重克制 V3。

太极概念拆三层，本次只覆盖「色」层；「形」（圆角 / 环形）与「动」（循环 loader）是独立工作线，v6 刻意棱角（6/8/12px）与标准 cubic-bezier 维持不变。

## 决策

1. **全族去冷蓝，换纯灰系**：bg/surface/neutral/border 全族一起换（只换 `--accent` 会冷暖斑驳）；明度阶梯沿用 v6 多轮对比度校准结果不变。
2. **accent 用中亮灰**（定稿 `#cfcfd4`）：微提自提案值避免比正文更暗导致可点击信号偏弱；`--accent-soft` / `--accent-ring` 走 `color-mix` 自动跟随。
3. **状态色保留极弱色相**（水墨绿/金/红/青/紫）：语义辨识下限——M/A/D 变更集 badge 必须能靠颜色分辨增删改，这是 V4 完全灰度被否的直接原因。
4. **换色前置 = 结构收敛**：硬编码冷蓝值全部 token 化（`--shadow-glow` / `--accent-ring` 等）、三真值源 6 项方向性分歧先裁决——否则旧色从缝隙冒出且无法对色。该前置已完成。

## 被否方案

| 方案 | 否决理由 |
|------|---------|
| 墨青（accent `#3a9b7e`） | 基底仍是冷色系，太极「黑白」纯粹感不够 |
| 墨朱（accent `#c95543`） | 暗底久盯生燥；红与 danger 语义天然冲突 |
| 纯太极浅克制 V1 | 状态色仍偏鲜艳（亮绿等），水墨克制感不足 |
| 纯太极中克制 V2 | accent `#d4d4d8` 偏亮，过曝感残留 |
| 纯太极极简灰度 V4 | 状态色零色相，M/A/D badge 无法分辨，语义损失过大 |

## 后果

- 亮色变体（皓族）当时未定，仅约定镜像重调、同灰度阶梯；暗色为默认主题。亮色值后来落于 `style.css` 的 `[data-theme=light]` 块。
- 「形」「动」两层如需太极感（加大圆角 / S 曲线 divider / 旋转太极 loader），须另开设计工作线并单独 demo 验证，不得夹带进色相变更。
- 色值后续调整一律改 `v6-tokens.css`（机器守卫 `check_css_token_ssot.py` 对照收录），不再维护文档色值表。
