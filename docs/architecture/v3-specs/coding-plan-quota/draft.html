布局原则：每个窗口严格一行（标签 | 进度条 | 百分比 | 剩余时间）。∞ 不显示：某窗口额度无限（未订阅/不支持）时整行隐藏，不占位。分档配色：<70% 蓝 / 70-90% 黄 / >90% 红。未配置 provider：浮层只保留容量区，footer 显示「无 Coding Plan」+ 配置按钮。
查询时机：hover 进入容量 chip 时主动触发一次查询（非后台轮询）。查询成功 → 更新缓存 + 展示；失败 → 展示旧缓存（不删除）+ runtime logger 落盘 log。并发保护：上一次未完成时不重复发起。
