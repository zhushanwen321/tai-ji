## 2. 与现有 features/ 剧本不一致（按源码为准）

1. **`features/session-management.md` 把 `session-detail-card` 当会话行**。实际它是 hover 详情卡
   （`SessionItem.vue` 里 Teleport 到 body 的 232px 浮层，含 cwd/分支/消息数），点它不会切会话。
   行根 = `.session-item`（`role=button`，`aria-label` = label）。`e2e/session-archive.spec.ts`
   的 `sessionRow()` 就是 `.session-item`。
2. **归档是两段确认**（`SessionItemActions.onArchiveClick`：首击只进 accent 确认态，
   title 变「再次点击确认归档」，二击才 emit archive）。剧本写「hover 出归档按钮 → 点击 → 已归档」。
3. **「彻底删除」不在归档摘要视图**：`archive-row-purge-btn` 在归档**列表行**悬停双钮里；
   `ArchiveSummaryView` 只有 `archive-restore-button`。剧本 Gotcha 写反了。
4. **steer 的「队列指示出现」不可靠**：steer 条目可能瞬间 `delivered`，`QueueBubble` 只显示
   未送达条目（queued/in-flight/failed）；且 `Alt+Enter` 的 followUp 在 wire 层与 steer 无区别
   （`delivery.submit` payload 无 intent 字段，runtime 取缺省 `interrupt-at-turn-boundary`）。
5. **`features/new-task.md` 不是错，是缺参数面**：`clientUuid`（幂等键）、`modelOverride` /
   `thinkingOverride`（Landing chip 覆盖）、`presetId`、`projectId`、`hidden` 六个参数完全没覆盖。

## 3. 查证失败 / 锚点缺口（最重要）

按影响排序：

1. **`ThinkingLevelPopover` 非聚合态的档位行没有 testid**（裸 `Button`，只能按中文 label 文本寻址）；
   聚合态才有 `thinking-level-row-<level>`。→ 需补 `thinking-level-<level>`。
2. **会话行没有 per-session testid / `data-session-id`**：只能 `.session-item` + aria-label/文本；
   同名 label 会双命中。→ 建议 `session-item-<sid>` 或 `data-session-id`。
3. **发送位没有 testid**：发送/停止/排队三态靠 `title`（`发送 · ⏎` / `停止` / `排队发送 · ⏎`）
   与 `stop-btn` class 区分。→ 建议 `composer-send-btn` / `composer-stop-btn`。
4. **thinking 行没有 header testid**：根锚 `block-thinking-<thinkingId>` 的 id 运行时才知道；
   稳定写法只有 `[data-testid^="block-thinking-"]` 或文本「思考」。→ 建议补 `thinking-block`。
5. **托盘行没有 record 标识**：`tray-workflow-row` / `tray-subagent-row` 每行同 testid，无
   `data-run-id` / `data-subagent-id`；workflow 的 slug 可缺省 → 并发同名 run 无法精确寻址。
6. **`session.delete` 没有用户 UI 入口**（单会话真删已迁移到归档域）：只能协议驱动，
   A 通道只能证明「列表消失」。剧本若写「在侧栏删除」必失败。
7. **`session.occupancy` 只有 state 帧 + subscribe 的 stateSnapshot 回放，没有 pull RPC**；
   漏帧后只能重新 subscribe（或等下一次状态变化）。
8. **`workflow.reconnect` 的 WS 断连驱动手法未实测**：`chromium context.setOffline` 是否稳定
   关闭 WS 未验证；当前只能复用 `e2e/workflow-disconnect-recovery.spec.ts`（E2E-SKILLRELOAD-04）。
   已在该 capability 里标 `待实测` 并给出替代路径（重开 overlay / 复用 e2e）。
9. **`session.create` 的 `hidden` / `clientUuid` 没有现成 UI 入口**（只能协议）；`clientUuid`
   幂等窗口是「短 TTL」，跨时长重试测不出来。
10. **`subagent.stream` 的内容帧是 transient**（不分配 seq）：无法用序号回放断言，只能
    `getSubagentStreamState` 拉取 + entry 权威链。
